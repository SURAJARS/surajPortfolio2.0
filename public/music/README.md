Note: To use the audio player, add an ambient.mp3 file to this directory.

The audio player will automatically:
- Attempt to load /public/music/ambient.mp3
- Allow play/pause control with the floating button
- Support volume adjustment
- Loop continuously when playing

You can add your own ambient music file or use a royalty-free track.
Recommended: Download from resources like:
- Pixabay Music (pixabay.com)
- YouTube Audio Library
- FreeMusic Archive
- Incompetech

Format: MP3 is recommended for best browser compatibility.
